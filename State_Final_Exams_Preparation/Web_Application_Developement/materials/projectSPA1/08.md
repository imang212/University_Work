# SPA: Single Page Application

- [TypeScript](https://www.typescriptlang.org) + HTML DOM
- [Node.js](https://nodejs.org) - runtime for JS + npm
- [Vite](https://vite.dev) - build tool

## Docker

`docker-compose.yml`

```bash
services:
  node-vite:
    container_name: node-vite
    build: .
    volumes:
      - ./app:/app
    ports:
      - 5173:5173 # vite
      - 8888:8888 # php
    tty: true
```

`Dockerfile`

```bash
FROM debian:stable-slim

RUN apt update && apt -y upgrade
RUN apt -y install mc nodejs npm php-cli
RUN npm install -g vite

RUN echo "PS1='\[\033[01;33m\]\u \[\033[01;34m\]\w\[\033[00m\] '" >> /root/.bashrc

WORKDIR /app
```

## Vite

#### Install ...

```bash
npm -v
npm -g list

cd /
npm create vite@latest app
# Vanilla, TypeScript

cd app
# package.json, tsconfig.json, ...

#vytvoření nového projektu
npm create vite new_project

npm install
```

... and run:

```bash
npm run dev -- --host # '-- --host' must be used, if in docker
```

#### Build ...

```bash
npm run build
```

... run it ...

```bash
cd dist
php -S 0.0.0.0:8888
```

... and open http://localhost:8888
